Two people use the same credit card. Only one of them owes the money.
That is the line between a primary cardholder and an authorized user.
The primary cardholder opened the account and signed the agreement with the bank.
They are legally responsible for every charge, including the ones others make.
An authorized user gets their own card on that account and can spend with it.
But they did not sign for the debt, so the bank cannot make them pay it.
The difference: the primary cardholder owns the debt, the authorized user only borrows the card.
Many issuers report the account to the authorized user's credit file too, so late payments can hurt them.
The primary cardholder can usually remove an authorized user at any time.
Same card, same account, but only one name on the bill.
